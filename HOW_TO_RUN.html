Agentic Warehouse MVP

How to Run This Project

Only Python is required. Nothing to install for the core app.

Run it in three steps

Check Python is installed

Open a terminal and run this. You need 3.8 or newer.

python --version

If it is not found, install it from python.org and tick "Add python.exe to PATH".

Start the server

From the project folder (the one holding app.py):

python app.py

On Windows you can instead double-click run.bat. Leave the terminal open — closing it stops the server.

Open the dashboard

In your browser go to:

http://localhost:8000

To stop the server, press Ctrl + C in the terminal.

Using the app

Toggle Stock IN or Stock OUT first — this decides what the scan does. Then feed it a code in any of three ways:

MethodHow
Camera Hold a QR code or barcode up to the webcam. Allow camera access when asked.
Sample chips Click a ready-made chip (ONT, Fiber Cable, IPTV Device, Remote, Raw Barcode). Easiest way to test.
Manual box Type a code and press Enter. Format is name,batch,productno — for example ONT,BATCH01,900001.

Every scan runs through all five agents and the dashboard shows the verdict (IN, OUT, or REJECT) plus the full agent trace.

Scan the same code as many times as you have units. Each IN adds one to the quantity, each OUT removes one. An OUT is only refused when the quantity is already zero.

The product number is what identifies a product. Scanning a plain barcode, or typing just a product number, matches whatever product already carries that number — it adds to or removes from the existing stock and keeps its name, category and batch. Only a product number never seen before shows as Unknown Item, and you can click name it in the inventory table to fix that for good.

Managing categories

You own the category list — the AI never files a product for you. Use the Categories panel at the bottom of the dashboard.

TaskHow
Add a category Type a name in the Categories panel and click Add category.
Rename or delete Use the rename / delete links on the row. Deleting moves its products to Uncategorised rather than losing them.
File a product Scan it, then pick a category in the prompt on the result panel and click Save. Or assign it later from the Products waiting for a category list.

A product the system has not seen before is filed as Uncategorised and the classifier offers a suggestion next to it. Your choice always wins, and it is remembered for every future scan of that product.

Low stock alerts & batches

Get warned before you run out

In the Live inventory table, type a number in the Reorder at column for any product. When stock falls to that number or below, a Low stock panel appears at the top of the dashboard. Set it back to 0 to switch the alert off.

The Forecast Agent also uses this level — it estimates how many days until a product hits its reorder point, not just until it hits zero.

Batch tracking

The batch number in a QR code (name,batch,productno) is now tracked. Stock of one product is held per batch, and the inventory table shows the split underneath the product name.

Router   Networking   qty 3
  BATCH-A - 2    BATCH-B - 1

Scanning OUT removes from the batch you scanned. If that batch is empty, the oldest batch still holding stock is used instead (FIFO) and the result panel tells you which batch it took.

Fixing mistakes

Undo the last scan

Click Undo last scan above the Recent activity table. It tells you exactly what it will reverse before you click. The undone scan stays in the audit trail, struck through, and the reversal is logged separately — nothing is ever silently erased.

Undo only reverses the single most recent scan. If those units have since been taken out, it refuses rather than pushing the count negative — correct the quantity by hand instead.

Correct a quantity by hand

In the Live inventory table, every batch under a product name has an editable number. Type the true counted quantity and press Enter or click away. It saves immediately and is recorded in the activity log as ADJUST, so a manual override is never mistaken for a scan.

Check everything works

The self-test runs the whole pipeline on a throwaway database. No browser needed.

python verify.py

Expect ALL CHECKS PASSED. If a check fails, its name tells you what broke.

Optional: the Claude assistant

The app has a built-in offline assistant that works with no setup. To upgrade it to Claude, install the package and set your API key:

pip install anthropic
set ANTHROPIC_API_KEY=sk-ant-...     (Windows)
export ANTHROPIC_API_KEY=sk-ant-...  (macOS / Linux)
python app.py

Without a key the assistant still answers, just locally. That is expected, not an error.

If something goes wrong

ProblemFix
python not found Install Python and add it to PATH, or try py app.py / python3 app.py.
Port 8000 already in use Run set PORT=8010 & python app.py, then open http://localhost:8010.
Camera will not start Allow camera permission and close other apps using the webcam. You can still use the sample chips and manual box.
No camera on phone Expected on plain HTTP. The camera needs HTTPS or localhost.
Want a clean database Stop the server, delete data/warehouse.db*, start again. It is recreated automatically.
Empty boxes instead of icons here This page loads Font Awesome from the internet. Cosmetic only — the app's own icons are local.
