i The Whole Project in Simple Words

If you read only one section, read this one.

A warehouse is a big storage building where goods are kept, tracked, and moved before they go to customers. Today most warehouses are run by one central computer that follows fixed rules and gives orders to everything. This works fine when everything is normal — but the moment something goes wrong (a rush of orders, a machine breaks, the internet drops), the whole system slows down or stops, because everything depends on that one brain.

This research proposes a smarter way: give every part of the warehouse its own small brain. A scanner, a sensor, a conveyor, a picking robot — each becomes an intelligent agent that can think for itself, talk to the others, and work together as a team. This is called a Multi-Agent System (MAS) powered by Agentic AI. Because there is no single brain, if one part fails the rest keep working. The warehouse becomes more flexible, easier to scale, and much harder to fully break.

One-line goal: Show that a warehouse made of many cooperating AI agents (decentralised) performs better, scales better, and recovers faster than a traditional single-controller warehouse (centralised) — especially in tough conditions like unstable internet and power cuts common in African settings.

Why this matters to us specifically: we are not starting from zero. We already built a real automated-warehouse project called AUTOWARE. That earlier work gives us proven code, a working QR-scanning module, and hands-on domain knowledge. This research is the natural next step — upgrading that centralised prototype into an intelligent, decentralised multi-agent system.

3 The Problem We Are Solving

Why today's centralised, rule-based warehouses fall short.

Weaknesses of centralised systems

  • Slow to adapt: can't react quickly to sudden demand or delays.
  • Single point of failure: if the central controller stops, everything stops.
  • Wasted resources: fixed rules assign tasks poorly, leaving machines idle or overloaded.
  • Hard to scale: struggles when the warehouse grows or workload spikes.

Extra challenges in African settings

  • Unstable or limited internet connectivity.
  • Frequent power outages (load-shedding).
  • High cost of advanced automation technology.
  • Limited access to AI expertise.
Research Question: How can Agentic AI-based multi-agent systems improve warehouse efficiency, scalability, and resilience?

The gap in existing research

Current smart-warehouse and IoT studies improve tracking and reduce manual work, but they mostly still rely on central control. The literature shows three gaps this project targets:

Little focus on real-time agent collaboration Weak integration of IoT + MAS + AI learning Almost no work on African-context conditions

4 The Big Idea — Agentic AI + Multi-Agent Systems

Turn every warehouse part into a small, smart, cooperating team-member.

Instead of one central brain, control is shared. Each agent senses its surroundings, decides on its own, talks to nearby agents, and cooperates to finish jobs. This is a decentralised design — flexible, adaptive, and fault-tolerant.

The three main agent types

Picker Agents

Decide which items to pick and when, based on incoming tasks and their own availability.

Transport Agents

Move goods around the warehouse, planning collision-free paths and cooperating to avoid jams.

Inventory Agents

Track stock in real time (using the QR-scanning ability) and tell other agents what is where.

5 The System Modules

The building blocks that make up the simulated multi-agent warehouse.

1. Agent Module

Defines each agent's brain: how it senses, decides, and acts independently. Includes Picker, Transport and Inventory agent behaviours.

2. Communication Module

The "language" agents use to talk — message passing so they can request help, share status, and coordinate in real time.

3. Task Allocation Module

Decides who does what. Instead of fixed rules, agents negotiate to take the jobs they are best placed to do.

4. Path Planning Module

Finds efficient, collision-free routes for many agents at once (multi-agent path finding), even as the layout changes.

5. Simulation Environment

A virtual warehouse built in Python — layout, items, and events — where all agents live, move, and are tested.

6. Sensing / Scanner Module

Item identification and tracking, reusing our existing QR_Scanner work as the inventory agents' eyes.

7. Evaluation Module

Collects performance data during experiments — timing, throughput, recovery — so results can be measured and compared.

8. Comparison Module

Runs the same tests on the old centralised system (AUTOWARE) versus the new MAS to prove the improvement.

6 How We Complete It — Methodology Steps

The research follows Design Science Research (DSR): build a real solution, then evaluate it. Six clear steps.

System Design

Design the multi-agent warehouse architecture and define the agent types — Picker, Transport, and Inventory agents — and how they relate.

Simulation Development

Build a simulated warehouse in Python: the layout, the tasks, and how agents interact with the space and each other.

System Implementation

Implement agent communication (message passing), the task-allocation strategies, and the path-planning algorithms that let agents cooperate.

Experimentation

Test the system under stress: high workload, equipment/device failure, dynamic task arrivals, and limited connectivity.

Evaluation

Measure performance: task completion time, resource utilisation, throughput, fault-recovery time, and scalability.

Comparison

Run the same tests on a traditional centralised system and compare — proving the gains in efficiency and reliability.

9 Expected Outcome & Contribution

What this research will demonstrate.

The project aims to show that Agentic AI-based multi-agent systems can significantly improve warehouse efficiency, scalability, and resilience compared to traditional centralised systems. Because control is distributed, the warehouse keeps running even when parts fail or connectivity drops.

What we expect to prove

  • Faster task completion and higher throughput.
  • Better use of available resources.
  • Quicker recovery after failures.
  • Smooth scaling as workload grows.

Why it matters

  • A practical, cost-effective solution for modern warehouses.
  • Especially valuable in developing regions with unstable power and internet.
  • Advances intelligent automation and multi-agent collaboration.
  • Builds directly on our proven AUTOWARE foundation.
