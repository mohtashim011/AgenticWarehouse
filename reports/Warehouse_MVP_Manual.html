Starting the application

The app is one Python program. It needs no installation — the Python standard library is enough.

Open the project folder

Everything lives in F:\moti\warehouse_mvp.

Launch the server

Double-click run.bat, or open a terminal and run:

# from the warehouse_mvp folder
python app.py

You will see: “Agentic Warehouse MVP is running … http://localhost:8000”.

Open it in a browser

Go to http://localhost:8000 (Chrome or Edge recommended). The dashboard loads.

Stop it when finished

Press Ctrl + C in the terminal (or close the run.bat window).

Nothing to install. The scanner, database, and AI pipeline all run on the Python standard library. The scanner and icon libraries are stored locally, so the interface even works without internet.

How to add an item (Stock IN)

Use this when goods arrive at the warehouse.

Select the direction

In the Capture panel, make sure Stock IN (green) is selected. It is the default.

Provide the code

Either scan with the camera, or type a code in the manual box. A QR code uses the format name,batch,productno (e.g. ONT,BATCH01,900001). A plain barcode is just its number.

Or click a sample

The chips (ONT, Fiber Cable, IPTV Device, Remote, Raw Barcode) submit a ready-made code instantly — ideal for testing.

Read the result

The AI Pipeline panel shows a green IN verdict, the counters update, and the item appears in Live inventory. Scanning the same product number again is rejected as a duplicate.

How to remove an item (Stock OUT)

Use this when goods leave the warehouse.

Switch to Stock OUT

Click Stock OUT (it turns red). All following scans now remove items.

Scan the same code

Scan or enter the exact product number that was previously scanned in (e.g. ONT,BATCH01,900001).

Item leaves stock

The verdict shows a blue OUT, the on-hand quantity drops, and the log records the exit. Trying to remove an item that is not in stock is rejected.

Remember to switch the direction back to Stock IN before receiving new goods.

Scanning with a real camera

QR codes and 1-D barcodes are decoded live inside the browser.

On a laptop (webcam)

  • Click Start camera and allow access when the browser asks.
  • Hold a QR/barcode inside the square. It is captured automatically — no button press.
  • The same code is ignored for 2.5 seconds to prevent accidental double counts.
  • Click Stop to release the camera.

On a phone

Browsers only grant camera access over HTTPS or localhost. Two options:

  • Simplest: keep using the laptop webcam.
  • Phone camera: expose the app over HTTPS with a tunnel, then open that URL on the phone:
# with the app running on port 8000
ngrok http 8000
# open the https://... address it prints, on your phone
Plain http://192.168.x.x will not give a phone camera — that is a browser security rule, not a bug in the app. Use HTTPS/localhost.

Supported code types

The decoder (ZXing, via html5-qrcode) reads QR plus common 1-D barcodes: EAN-13/8, UPC-A/E, Code 128, Code 39, ITF and others.

How each agent works (the methods)

Every scan is passed, in order, through five independent agents coordinated by an orchestrator. Each one senses, decides, and hands its result to the next — the decentralised design from the research proposal.

Scanner Agent

Perception · rule-based parsing

Takes the decoded string. If it contains commas it is treated as a QR payload (name,batch,productno); otherwise the whole value is a barcode / product number. It cleans the fields and sets a confidence score.

Reliability: deterministic — 100% on well-formed input.

Classifier Agent

Machine learning · Multinomial Naive Bayes

Predicts the product’s category from its name. Words are tokenised into a bag-of-words; class priors and word likelihoods (with Laplace smoothing) are learned from a labelled training set; the category with the highest posterior wins. Catalogued names are matched exactly first.

Accuracy: 100% catalogue · ~70–83% novel names (see below).

Inventory Agent

Decision · state machine

Owns the live stock. On IN it accepts an item only if that product number is not already in stock; on OUT it accepts only if the item is currently in stock. It then writes the change to the database.

Reliability: deterministic — rules are always applied correctly.

Anomaly Agent

Statistics · rules + online mean/σ

Flags double-reads (same code within 1.5 s), abnormal scan-rate spikes (a z-score outlier on the time between scans, computed with Welford’s online algorithm), unknown/uncatalogued items, and rejected moves. A combined score ≥ 0.5 raises a flag.

Behaviour: explainable — every flag lists its reason; thresholds are tunable.

Forecast Agent

Forecasting · average consumption

Estimates an average daily out-rate from the OUT history and divides current on-hand quantity by it to predict days-to-stock-out, warning when under three days remain.

Behaviour: indicative — sharpens as more history accumulates.

Orchestrator

Coordination

Runs the agents in order, records each message as a trace, commits the log entry, and returns everything to the interface so the teamwork is visible.

Role: the conductor of the multi-agent pipeline.

Accuracy — measured, not guessed

As an MVP this is a working demonstrator, not a production system. Here are the honest numbers and the reasoning behind them.

~99%QR / barcode decode on clear, well-lit codes
100%Classifier on catalogued product names
70%Classifier on novel names (leave-one-out CV)
83%Classifier on an unseen spot-check set

Component-by-component

ComponentMethodAccuracy / behaviourHow it was assessed
Code decodingZXing (html5-qrcode) ~99% on clear codes; drops with blur, glare, steep angles or low light. Well-established library benchmark; depends on camera & print quality.
Scanner AgentRule parsing 100% for well-formed input; lowers its own confidence on odd characters. Deterministic — no learning involved.
Classifier (catalogue)Exact match 100% — known names map directly to their category. By construction.
Classifier (novel names)Naive Bayes 70% LOO-CV overall — Entertainment 5/5, Networking 6/9, Accessories 3/6; 83% on 6 unseen test names. Leave-one-out cross-validation on the 20-sample training set + a held-out spot check.
Inventory AgentState machine Exact — duplicates and impossible removals are always caught. Verified against IN/duplicate/OUT/not-in-stock test cases.
Anomaly AgentRules + statistics Deterministic for its defined patterns; sensitivity set by thresholds (1.5 s window, z < −2.5). Detects the exact patterns it is designed for; not a trained classifier, so no false-negative rate is claimed.
Forecast AgentMoving average Indicative — a rough estimate that needs several OUT events to be meaningful. Simple average model; accuracy improves with data volume.
Why the classifier is only ~70% on new names. It is trained on just 20 labelled examples. With so little data, rare or ambiguous words (e.g. “screw pack”) are misread. This is expected for an MVP and is the single easiest thing to improve.

How to raise the accuracy

  • More training data — a few hundred real product names would push category accuracy well above 90%.
  • Better features — TF-IDF weighting or word embeddings instead of raw word counts.
  • Confidence gating — when the top category scores below, say, 50%, ask a human to confirm.
  • A trained anomaly model — an Isolation Forest on real scan features once enough history exists.
  • Higher-quality labels & lighting — clean, flat, well-lit codes keep decoding near 99%.

Troubleshooting

SymptomCause & fix
Page will not openThe server is not running. Run python app.py and use http://localhost:8000.
“Port already in use”Another copy is running. Close it, or start with a different port: set PORT=8010 & python app.py.
Camera will not start (laptop)Allow camera permission in the browser; close other apps using the webcam.
No camera on phoneExpected over plain HTTP — use HTTPS/localhost (see the Camera section).
Icons look like empty boxesFont Awesome needs internet; the app’s own Lucide icons are local and always show. Reconnect, or ignore — it is cosmetic.
Assistant says “offline”No ANTHROPIC_API_KEY set. That is fine; set the key to use Claude.
Want a clean startStop the server and delete data\warehouse.db; it is recreated empty on the next run.
